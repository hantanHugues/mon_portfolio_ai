# Images du Portfolio

## Photo de Profil

### Fichier requis : `profile.png`

**Spécifications recommandées :**
- **Format** : PNG (pour transparence)
- **Dimensions** : 400x400px minimum
- **Qualité** : Haute résolution
- **Background** : Transparent ou supprimé
- **Style** : Photo professionnelle, sourire naturel

### Comment préparer votre photo :

1. **Suppression du background :**
   - Utilisez [remove.bg](https://www.remove.bg) (gratuit)
   - Ou Photoshop avec l'outil de sélection
   - Ou Canva Pro avec l'outil Background Remover

2. **Optimisation :**
   - Redimensionnez à 400x400px
   - Sauvegardez en PNG pour garder la transparence
   - Compressez avec [TinyPNG](https://tinypng.com)

3. **Placement :**
   - Placez le fichier `profile.png` dans ce dossier
   - Le chemin sera automatiquement `/images/profile.png`

### Alternative si pas de photo :

Si vous n'avez pas de photo, vous pouvez :
- Utiliser un avatar généré (Gravatar, Bitmoji)
- Créer un logo personnel
- Utiliser vos initiales stylisées
